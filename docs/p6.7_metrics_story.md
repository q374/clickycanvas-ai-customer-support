# ClickyCanvas AI 客服 Agent：指标与评测页

版本：P6.7 面试版｜日期：2026-10-11

## 1. 一句话结论

项目把“模型回答看起来不错”拆成需求理解、候选召回、排序、事实边界、工具安全和顾客可见体验，先建立固定回归，再用独立挑战和盲评暴露过拟合与话术问题。

## 2. 固定评测：修复前后

## 3. 模型对照

同一冻结集上的 DeepSeek 对照：案例通过率 33/33，模型回退率 6.06%（2/33），P95 1729.21ms；deterministic P95 为 11.75ms。设计取舍是让 deterministic/工具层掌握事实、路由和安全，DeepSeek 只在证据保护下润色语言。

## 4. 独立挑战与人工盲评

- 独立挑战：60 个案例、70 个轮次，deterministic 案例/轮次通过率 96.7%/97.1%，DeepSeek 为 83.3%/85.7%，两者安全边界违规均为 0。
- 人工盲评：12 题，项目本人完成，证据等级为 `owner_blind_review`；总体通过 8/12，A 偏好 1，B 偏好 4，相同/无法区分 7。
- 盲评暴露：内部套话、候选数量不一致、政策回答过长、不自然的“我们直接继续处理”。这些问题已修复，但尚未对修复后版本重新盲评。

## 5. 修复后回归

- 售前评估：58/58；
- 固定评估：84/84；
- 购物、情绪、工具、holdout 单元测试：32/32。

## 6. 面试时的边界表述

可以证明：固定场景没有回归、失败有归因、工具有边界、回答体验根据反馈迭代。

不能证明：真实用户满意度、线上转化率、生产 SLA、跨商家泛化能力。项目仍是可演示的 AI Agent 原型，而不是已上线客服平台。
