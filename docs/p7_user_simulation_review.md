# P7 用户体验模拟复盘

更新时间：2026-10-11

## 模拟范围

本轮使用隔离数据库 `data/runtime/ux-sim.db`，在 `http://127.0.0.1:8803/` 通过页面按普通顾客语言操作，避免已有测试案件影响观察。覆盖以下任务：

- 不明确需求：“我想买个键盘”→补充“办公，预算800以内”；
- 推荐后的商品追问：“第一款支持 Mac 吗？”；
- 退货政策：未拆封商品能否退货；
- 订单查询：先只提供订单号，再单独提供 4 位验证码；
- 高风险售后：到货损坏并要求退款；
- 能力边界：询问“你会做什么？”；
- 会话操作：清除选购条件后重新开始；
- 批量回归：33/33 盲测、58/58 售前案例、84/84 业务案例通过。

## 发现与修复

- 回复默认暴露意图、模型名称和追踪 ID，增加了顾客阅读负担。现在技术元信息收进“查看回答依据”，仍保留复盘入口。
- “清除会话记忆”不符合普通顾客语言。按钮改为“重新开始”，无障碍名称保留完整动作说明。
- 快捷入口“清空选购条件”与会话按钮含义接近。快捷入口改为“重新开始选购”。
- 页面原来没有明确输入提示。新增说明：可以描述使用场景、预算、商品型号、政策或订单号；缺少信息时会继续追问。
- 页面状态从“DeepSeek 已润色”等内部术语改为“已结合智能理解回答”“已使用可靠规则回答”“已转人工处理”等顾客可理解的表达。
- 手机宽度下商品卡片改为单列，降低卡片文字过密的问题；补充键盘焦点样式。

## 证据与限制

- 这是开发者模拟，不是独立用户满意度调查；尚未证明真实顾客能顺利完成任务。
- API 和页面调用均使用演示商品、政策和模拟订单；售后案件只写入本地数据库。
- 评估集能证明固定场景的行为约束，不能替代真实问法和真实业务数据。

## 下一步

请用户作为第一次使用者完成一轮自然试用，优先不看预设按钮，直接输入自己的问题。建议依次尝试：

1. “我想买个键盘，但不知道怎么选”；
2. 补充一个使用场景和预算；
3. 追问某一款是否支持自己的设备；
4. 查询订单但先不输入验证码，再补验证码；
5. 提出退货或到货损坏问题。

记录哪里看不懂、哪里觉得重复、是否知道下一步，以及回答是否足以做决定，再决定下一轮修改。
